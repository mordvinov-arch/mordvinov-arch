# mordvinov-arch

Research engineer building reproducible transcriptomic scores and vibration-diagnostics tools.

- [sepsis-score](https://github.com/mordvinov-arch/sepsis-score) — five-module transcriptomic sepsis score (AUC 0.93–0.95, four GEO cohorts).
- [luad-prognostic-scores](https://github.com/mordvinov-arch/luad-prognostic-scores) — B-cell, hypoxia, metabolic and immuno scores for lung adenocarcinoma.
- [earlybearing](https://github.com/mordvinov-arch/earlybearing) — vibration snapshots to a bearing health passport (false-alarm control, defect onset).
